# SockShop — Учебный интернет-магазин носков

Учебный проект интернет-магазина, разработанный на Django.  
На текущем этапе реализован базовый фронтенд и структура страниц.

---

## Реализованные страницы

- **Главная** — приветственная страница с баннером и краткой информацией.
- **Каталог** — отображение списка товаров (носков).
- **Категории** — фильтрация товаров по категориям.
- **Контакты** — контактная информация.
- **404** — кастомная страница ошибки.
- **Всплывающее меню** — адаптивное мобильное меню (бургер).
- **Форма обратной связи** — с выводом данных в консоль (для отладки).

---

## Технологии

- Python 3.14
- Django 5.2.17
- HTML5 / CSS3
- Bootstrap 5 (адаптивная вёрстка)
- Django Templates

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone git@github.com:molochkoannav/app.git
```

## Создание виртуального окружения
```
python -m venv venv
source venv/bin/activate   # Linux/Mac
venv\Scripts\activate      # Windows
```

## Установка зависимостей
```
pip install -r requirements.txt
```

## Создание суперпользователя (опционально)
```
python manage.py createsuperuser
```

## Запуск сервера разработки
```
python manage.py runserver
```
После запуска перейдите по адресу: http://127.0.0.1:8000/
